# ASCamera Example App

A full, buildable iOS app for exercising the ASCamera library on a real device. It contains **two
recorder screens with different layouts** built on the same library, plus a recordings library that
proves each clip carries its **recording-start timestamp inside the file**.

## Run it

> The camera is unavailable in the iOS Simulator — run on a **real device**.

1. Open `ASCameraExample.xcodeproj` in Xcode.
   *(The project references the ASCamera package one directory up, via a relative path.)*
2. Select the `ASCameraExample` target ▸ **Signing & Capabilities** ▸ pick your development team.
3. Choose your device and **Run**.

Camera & microphone usage descriptions are already configured (generated into the Info.plist by
the build settings), so no extra setup is needed.

### Regenerating the project

The `.xcodeproj` is generated by [XcodeGen](https://github.com/yonaskolb/XcodeGen) from
`project.yml`. If you change the file list or settings, regenerate it:

```bash
cd Examples/ASCameraExample
xcodegen generate
```

## What's inside

| Screen | Layout | Configuration |
|--------|--------|---------------|
| **Full-Screen Recorder** | Edge-to-edge preview, floating shutter + timer pill + flip button. | Back camera, 1080p/30, follows device orientation, 60 s max. |
| **Card Recorder** | Framed "card" preview on a light panel, controls in a bar below. | Front camera, locked portrait, standard stabilization, 15 s max. |
| **Recordings** | List + detail player. | Reads back the embedded start time from each file. |

Both recorders are thin UIs over the library:

- `CameraPreview(camera:)` for the live feed.
- `try await camera.start()` in `.task`.
- A consumer-built record/stop button calling `startRecording(outputURL:)` / `stopRecording()`.
- The timer label is driven by `camera.recordingDurationStream()` — no manual `Timer`.
- Completed clips (including 15 s/60 s auto-stops) arrive via `camera.recordingFinishedStream()`.
- `CameraPermissionErrorView` is shown automatically when permission is missing.

## The recording-start timestamp

Every recording is tagged with the moment it began, in **two** places:

1. **Inside the file** — ASCamera writes a QuickTime `com.apple.quicktime.creationdate` metadata
   item (ISO-8601) into the `.mov`. The **Recording** detail screen reads it back with AVFoundation
   and shows it as "Recording started". You can also confirm it externally:

   ```bash
   ffprobe -v error -show_entries format_tags=creation_time -of default=nk=1:nw=1 rec-….mov
   ```

2. **In the file name** — clips are saved as `rec-YYYY-MM-DD_HH-mm-ss.mov` under the app's
   `Documents/Recordings`, so the start time is visible at a glance (and via Finder when File
   Sharing is enabled for the app).
